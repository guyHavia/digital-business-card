01 About

I’m an AI engineer with seven years in production ML and LLM systems, most of it on the seam between a model and the software around it: agent orchestration, tool use, and the harnesses that keep both honest. Right now that means LangGraph for the control flow and LangChain for the parts that touch retrieval and tools.

I’ve built an agent harness that replays every graph node against golden traces before it ships, a retrieval pipeline a support team leans on daily, and an eval suite two other teams have since adopted. I also write, mostly about what actually changes in how you code once an agent is doing the typing: what skills get sharper, what atrophies, and how to tell the difference on purpose.

Outside the editor I climb at a bouldering gym in Florentin, restore mechanical keyboards badly, and am slowly working through a very long list of Spanish verbs.
